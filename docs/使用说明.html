🚀 快速开始（本地开发）

# 1. 创建虚拟环境并安装依赖（Python 3.11+）
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt

# 2. 配置 .env（复制 .env.example 修改：MySQL 连接、DeepSeek API Key、渠道密钥）
copy .env.example .env

# 3. 初始化数据库（建表 + 管理员 + 内置定时任务，幂等可重复执行）
$env:FLASK_APP = "run:app"
.\.venv\Scripts\python -m flask init-db

# 4. 启动（默认 http://127.0.0.1:5000）
.\.venv\Scripts\python run.py

# 终端维护（项目根，先 $env:FLASK_APP = "run:app"）
.\.venv\Scripts\python -m flask reset-admin-password --username admin
.\.venv\Scripts\python -m flask reset-db --yes

默认管理员：admin / admin123 —— 登录后请立即到「设置 → 账号」修改密码。忘记密码用上面的 reset-admin-password（省略 --password 会打印一次随机密码）。reset-db 会 DROP 全部数据表，不加 --yes 只列出表名。

💪🧳💰 健身 / 出行 / 消费

这三个模块在左侧导航的「生活」分组，页面、定时任务、AI 对话都能用。

健身 /fitness/

  • 记录：日期、类型（跑步 / 力量训练 / 游泳 / 骑行 / 瑜伽 / 球类 / HIIT / 其他）、时长、强度（低/中/高）、卡路里、体重、备注
  • 看板：训练次数、总时长、总消耗、最近体重
  • 定时：每天 20:00「该去健身啦」；每周日 19:00 根据近 7 天记录生成周分析并推送
  • 对话示例：「今天跑步 40 分钟」「帮我分析一下这周健身」

出行 /travel/

  • 计划：目的地、往返日期、交通方式（可多选）、多段交通（出发地/到达/时刻/历时/购票平台）、备选方案、预算、同行人
  • 点「生成行程」：AI 按天数写出逐日安排（上午/下午/晚上 + 餐饮住宿建议），保存在该计划里
  • 定时：每天 09:00 检查「明天出发」的计划，有则推送收拾行李提醒
  • 对话示例：「帮我规划下周五去杭州，高铁往返」

消费 /expenses/

  • 记一笔：金额、分类（餐饮/交通/购物/娱乐/居住/医疗/教育/旅行/其他）、日期、支付方式（微信/支付宝/现金/银行卡/其他）
  • 可按月份筛选；看板显示总支出、笔数、分类占比、按月汇总
  • 对话示例：「午饭 38 块微信支付」「这个月花了多少」

给手机 App 用的消费接口（可选）

到「设置 → 账号」生成你自己的 Token（数据记在你的账号下）。也可以在 .env 写全局 API_TOKEN（会记到第一个管理员，仅作兼容）。请求头带：

X-API-Token: 你的Token
# 或
Authorization: Bearer 你的Token
方法路径说明
GET/api/v1/expenses列表（可用 start_date / end_date / category / limit）
GET/api/v1/expenses/stats统计
GET/api/v1/expenses/<id>详情
POST/api/v1/expenses创建，JSON：amount / category / date / payment_method / notes
PUT / PATCH/api/v1/expenses/<id>更新
DELETE/api/v1/expenses/<id>删除

没配任何 Token 时这些接口一律 401，不会裸奔。每个用户的 Token 只能读写自己的账单。

⚙️ 重要设置

🌐 网页站点（推荐只填端口）

在「设置 → 系统 → 网页站点」配置。公开网页不必配 HTTPS、也不必配域名：

项示例作用
网页端口8080独立 HTTP 端口，访问 http://局域网IP:8080/页面slug
链接主机可留空留空则自动用本机局域网 IPv4

保存后立即监听。防火墙放行该 TCP 端口即可。域名/证书属于高级选项，已有 Nginx 反代时才需要。

🤖 飞书机器人接入方式

「设置 → 通知 → 飞书」可选两种收消息方式（发消息/通知不受影响）：

  • HTTP 回调：开放平台把事件 POST 到 /feishu/event，需要公网 HTTPS 回调地址。
  • 官方 SDK 长连接：安装 lark-oapi 后，进程主动连飞书，不必暴露回调。开放平台事件订阅请选「使用长连接接收事件」。保存配置后本页可看到连接状态。 注意：长连接不需要入站公网端口，但 AI 构建的网页要在飞书里打开，必须有公网 IPv4。未连公网、没有公网 IPv4 时，飞书里无法显示构建的网页。

两种方式不要同时开，否则可能重复回复。切换后若长连接没立刻断开，重启一次应用即可。

🧠 模型接入（每人自己的 Key）

「设置 → AI → 模型与人设」：每位用户必须填写自己的 API Key，不能使用管理员或服务器 .env 里的 Key。

  • OpenAI 兼容：官方 OpenAI、DeepSeek、通义、Kimi、Ollama、各类中转。走 /chat/completions + Function Calling。
  • Anthropic：Claude 官方或兼容网关。走 /v1/messages + tool_use。地址填 https://api.anthropic.com，模型如 claude-sonnet-4-5。

「快捷填入官方地址」按国内 / 国际 / 本地分组：DeepSeek、通义、Kimi、智谱、豆包、硅基流动、星火、混元、OpenAI、Claude、Grok、Gemini、Ollama 等。点一下即填入该厂商的 Base URL 和默认模型名，再粘贴你自己的 Key，保存即生效，可点「测试连接」。

🎭 对话人设

「设置 → AI → 模型与人设 → 对话人设」：改 AI 的名字、性格（默认助理 / 专业干练 / 温柔陪伴 / 幽默机智 / 讲解老师 / 行动教练 / 自定义）、怎么称呼你、回复详细度、立即回复，以及一段补充说明。保存后下一轮对话生效。查日程、记账等工具规则不会被覆盖。

立即回复：消息一到先发一句确认，再给出正式回答。默认 收到：{message}。可改成任意文案，也可用变量 {message}（用户原话，过长会截断）、{name}（助手名）、{address}（对你的称呼）。取消勾选「先立即回复，再作答」则关掉。网页对话在同一条气泡里先出确认；飞书会先单独发一条，再发正文。

🖼️ 图片生成配置

「设置 → 生成 → 图片」填入 BaseURL / API Key / 模型（任何 OpenAI 兼容图片服务，如硅基流动 https://api.siliconflow.cn/v1、FLUX/Kolors、OpenAI gpt-image 系列）。保存即生效，可「测试生成」验证。

🧩 技能安全说明

重要：技能是 AI 生成的 Python 代码，在受限沙箱中执行（禁止 import / 文件 / 网络 / 子进程）。这是「尽力而为的护栏」而非强安全边界——启用前务必点「代码」人工审查。新建技能默认禁用。

🧠 记忆梳理

内置任务「上下文梳理」默认每日 04:00 自动执行（长对话压缩 + 抽取长期记忆）；也可在「🧠 记忆」页手动「立即梳理」。自动抽取的记忆可单条删除；手动记录的（remember）不会被自动覆盖。

👥 用户管理（仅管理员）

「设置 → 账户 → 用户」可创建新账号（自动带上该用户的内置定时任务），并把飞书 open_id（以 ou_ 开头）绑到某个账号。各用户的日程、任务、笔记、对话、健身、出行、消费互相隔离。

🔒 后台安全入口（可选）

在 .env 设置 ADMIN_ENTRY=一段随机路径 后重启，后台变成 https://你的域名/<入口>/login。不带入口访问后台会 404；公开网页和飞书回调不受影响。

🚀 部署（宝塔 / 普通服务器 / Docker / MySQL）

完整逐步教程请打开仓库 docs/部署.md，覆盖：环境要求、MySQL 建库连库、宝塔面板、普通 Linux（systemd）、Docker、网页 HTTP 端口、飞书两种接入、备份与安全清单。

三种方式怎么选

方式适合
宝塔面板已装宝塔：用 Supervisor + waitress 监听 8000，MySQL 用面板安装
普通 Linux无面板的 Ubuntu/Debian：venv + systemd，可选 Nginx
Dockerdocker compose up -d --build app；自带 MySQL 加 --profile mysql

必须知道

  • 只能 1 个 worker（waitress 或 gunicorn -w 1）。多进程会让定时任务和飞书消息重复。
  • 不要用 uvicorn。MySQL 库要先建好，字符集 utf8mb4。
  • 公开网页推荐只填端口（设置 → 网页站点），不必配 HTTPS / 域名；云安全组要放行该端口。
  • Docker 里连宿主机 MySQL 填 MYSQL_HOST=host.docker.internal，不要填 127.0.0.1。
  • 安装打开 /setup，令牌在服务器 data/setup_token.txt。每次从第①步开始，保存连接后才到第②步；有数据表也不会自动跳过。可「开始初始化」继续，或先「重置数据库」（DROP 全部表，需令牌和二次确认，不改 .env）。用户名已存在则第③步报错，需换名或先重置。
  • AI 对话走 SSE：若前面有 Nginx，必须 proxy_buffering off。
# Docker 接已有 MySQL（无域名）
cp .env.example .env          # 填 MYSQL_* / LLM_API_KEY / PAGE_PORT
docker compose up -d --build app
docker compose exec app python -m flask init-db

# Docker 自带 MySQL 8
# .env 里 MYSQL_HOST=db
docker compose --profile mysql up -d --build app db
docker compose exec app python -m flask init-db

🛠️ 改功能流程（维护者）

改功能、修缺陷、改页面或接口时，按仓库 Skill .grok/skills/edit-flow/SKILL.md（对话里 /edit-flow）执行，不要直接开改：

  1. 先阅读相关源码和现有测试，说明当前实现
  2. 至少两轮提问，确认需求与边界（空值、未登录、局域网、短入口、旧链接等）
  3. 按确认范围改代码
  4. 用 .venv 跑 scripts/ 里对应测试
  5. 测试通过后，再同步 docs/PROJECT.md、README.md、本页对应章节

错别字、注释、纯格式可以不走全流程。细则以 Skill 为准。

🔒 安全提示（公网部署必读）

  • 务必修改默认密码 admin/admin123；SECRET_KEY 改成随机长字符串
  • SESSION_COOKIE_SECURE=1（HTTPS 下）；登录接口已限流（10 次/分钟）+ CSRF 防护 + 密码哈希存储
  • 所有业务数据软删除可回滚；每日自动备份
  • 技能启用前人工审查代码；生成网页/图片公开前确认内容合规
  • 给 App 开接口时用「设置 → 账号」生成 Token（或足够长的 API_TOKEN），不要提交进 git
  • 公网建议配置 ADMIN_ENTRY，避免后台路径被扫到
  • 保管好 data/setup_token.txt：/setup 装好后仍可打开，持有令牌就能改库配置、DROP 全部表或再建管理员（与设置页「清空业务数据、保留账号」不是一回事）
  • 能登录服务器的人可用 flask reset-db --yes / flask reset-admin-password，不必经过网页令牌。不要把生产机器 shell 随便给人
