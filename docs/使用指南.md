# 使用指南

[返回首页](../README.md) · [安装与升级](部署.md) · [开发指南](开发指南.md)

## 先完成这三件事

1. 登录后在「设置 → 账号」确认密码、时区和外观偏好。
2. 在「设置 → 模型与人设」填写接口协议、接口地址、API Key 和模型 ID，再测试连接。每位用户使用自己的配置。
3. 如果需要推送，配置「设置 → 渠道」；如果需要在飞书聊天，按 [飞书接入说明](部署.md#飞书机器人) 配置应用机器人并绑定账号。

聊天模型、提示词、图片生成和备用识图都可保存多组配置，分别切换。只使用文字聊天时，先配置聊天模型即可。

## 直接告诉 AI 要做什么

| 你可以这样说 | AI 可以完成的操作 |
|---|---|
| “明天下午 3 点开会，提前 10 分钟提醒。” | 创建日程、检查时间冲突、设置提醒 |
| “把本周还没完成的任务列出来。” | 查询任务 |
| “记一下这次会议的三个结论……” | 保存笔记 |
| “每天 9 点半提醒我喝水。” | 创建定时提醒 |
| “把明天的日程发到飞书。” | 查询日程并推送 |
| “做一个展示项目的个人主页。” | 生成 HTML 网页和访问链接 |
| “调研一下这个主题，整理来源链接。” | 搜索资料并生成调研网页 |
| “今天跑步 40 分钟。” | 记录健身 |
| “规划下周五去杭州的高铁行程。” | 建立出行计划和逐日行程 |
| “午饭 38 元，微信支付。” | 记录消费 |

日历、任务、笔记、网页和生活记录也都有独立管理页面，可随时查看和修改 AI 创建的内容。

## 模型与上下文

### 保存多家模型与快速切换

在「设置 → 模型与人设」给配置组命名，填写协议、地址、API Key 和默认模型，再点击「保存为新组」。每组独立保存服务商、模型、思考等级、上下文容量和读图能力。以后从「已存模型配置」下拉选择并切换即可，修改现有组使用「保存当前组」。

提示词与人设、图片生成、备用识图也可分别保存多组。后台切换会更新该类配置的默认选择；聊天的会话设置中有四个快捷下拉，可为当前对话选择模型、提示词、图片生成与备用识图配置。

### 模型和思考等级

在「设置 → 模型与人设」的候选模型中，每行填写一个模型 ID。候选项共用当前用户的接口协议、地址和 API Key，必须是该接口实际可用的模型。

`/model` 只切换当前组内的模型 ID。选择非默认模型时，不会继承原默认模型声明的上下文容量与视觉能力：容量恢复未指定，读图能力改为自动识别。容量或视觉能力不同的模型，请分别保存为配置组并用 `/profile` 切换；切回组内默认模型会恢复该组声明的能力。

网页聊天提供下拉菜单和操作按钮；网页与飞书也支持同一组命令：

| 命令 | 作用 |
|---|---|
| `/`、`/help` | 查看帮助 |
| `/profile`、`/profile 配置ID` | 查看或切换模型配置组，包括服务商和上下文容量 |
| `/prompt`、`/prompt 配置ID` | 查看或切换提示词与人设 |
| `/image`、`/image 配置ID` | 查看或切换图片生成配置 |
| `/vision`、`/vision 配置ID` | 查看或切换备用识图配置 |
| `/model` | 查看当前模型及带序号的候选列表 |
| `/model 2`、`/model 模型ID` | 切换当前会话的模型 |
| `/think` | 查看当前模型支持的思考等级 |
| `/think high`、`/think default` | 使用指定等级，或恢复模型默认行为 |
| `/auto on`、`/auto off` | 开关 AI 自主切换 |
| `/context`、`/status` | 查看模型、摘要和上下文用量 |
| `/compact` | 立即压缩较早上下文，需要可用模型 |

新会话默认允许 AI 自主切换，调整可在同一轮的下一次模型请求生效。手动选择模型或思考等级后会锁定选择，发送 `/auto on` 可恢复自主切换。所有切换仅影响当前会话。

可选思考等级以界面或 `/think` 返回结果为准。无法识别能力的模型接口只提供 `default`。

### 模型上下文容量与压缩

每组模型可声明其本身支持的上下文容量：32K、64K、128K、256K、512K、100 万、200 万 tokens，或自定义 32,000–10,000,000 tokens。**填写值应与实际模型和接口支持的容量一致；选择更大的数值不会扩展模型本身的上限。** 容量不同的模型建议分别保存为配置组，聊天切换配置组时即可一并切换容量。

系统会为回答、工具和系统提示词预留空间，按所选模型容量管理历史上下文；接近容量时自动压缩可压缩的较早轮次。也可点击聊天中的压缩按钮或发送 `/compact`。沿用原设置的配置保留原有的压缩触发规则。

后续请求使用摘要和近期消息，通常保留最近 8 条用户 / 助手消息；较小容量可能进一步压缩旧轮次，最新完整用户轮次始终保留。**完整聊天记录仍保留**；压缩失败或摘要没有有效缩短时，会继续使用原上下文。

摘要可能省略细节，重要原文可回看聊天记录。页面上的 token 数是字符估算，不是服务商账单用量。

### 人设与长期记忆

- 「设置 → 模型与人设 → 提示词与人设」可保存日常助理、写作伙伴等多套提示词，包含名字、语气、称呼、详细度与补充说明。切换后下一轮对话生效。
- 可以说“记住我喜欢简短回答”，也可在「记忆」页查看、删除长期记忆。
- 「上下文梳理」定时任务会为较长会话生成摘要，并提取跨会话记忆；可在「定时任务」调整时间，或在「记忆」页手动执行。

## 网页和图片

### 生成并分享网页

1. 对 AI 说“帮我做一个……网页”，或进入「网页」手动新建。
2. 在「网页」页编辑源码、预览、复制或调整公开状态。
3. 需要外部分享时，由管理员在「设置 → 网页站点」填写公网访问地址，例如 `https://pages.example.com`。

公网访问地址只填协议、主机和可选端口，不带页面路径。AI 创建、修改或复制公开网页后，会使用这个地址返回链接；公开图片也使用同一根地址。

这个设置负责生成链接，服务器端口或反向代理仍需先打通，见 [公开网页部署](部署.md#公开网页)。私有页面需要登录，隐藏页面会返回 404。

### 生成、修改和识别图片

- 在「设置 → 图片」填写兼容的图片服务地址、密钥和模型，命名后保存为配置组；可预存多家服务并用下拉或 `/image` 切换。然后说“帮我画一张……”，或进入「图片」页生成。
- 说“把这张图的背景改成黄昏”可触发改图；接口不支持编辑时，会结合原提示词重新生成，结果未必保留原图细节。
- 图片库支持下载、删除和公开 / 私有切换。公开图片可以嵌入网页。
- 在网页聊天点击「上传图片」，或直接向飞书机器人发送图片，即可识别图片内容。网页支持 PNG、JPEG、WebP、GIF，单张不超过 8 MiB。
- 聊天模型支持视觉时，优先调用当前模型的原生读图能力；不支持时使用「设置 → 视觉」选中的备用识图配置。该配置支持 OpenAI 兼容和 Anthropic 协议，也可保存多组并用下拉或 `/vision` 切换。
- 未知模型可在其配置组中手动指定是否支持读图。原生读图不可用且没有备用视觉配置时，图片只保存，不会伪造识别结果。

语音输入和朗读在聊天页使用；「设置 → 语音」可配置 TTS，未配置时使用浏览器朗读。可用性取决于浏览器及其权限。

## 搜索、知识库和技能

**联网搜索：** 在「设置 → 联网搜索」选择提供方并点击测试。可用选项包括 Bing、DuckDuckGo、SearXNG、Serper 和 Tavily；后两者需要对应密钥。实际连通性以部署网络和测试结果为准。

**知识库：** 调研完成后说“收录进知识库”，AI 会提炼内容保存为笔记。配置 `EMBEDDING_BASE_URL / EMBEDDING_API_KEY / EMBEDDING_MODEL` 后，可对笔记、网页和会话摘要做语义检索；未配置时回退到关键词搜索。

**自定义技能：** 说“创建一个把文字转成首字母大写的技能”，AI 会生成 Python 工具。新技能默认禁用，需要在「技能」页查看代码后手动启用，也可随时停用或删除。技能在服务器子进程中执行，设有超时和静态检查；这些措施不能替代启用前的代码审查。

## 生活记录与提醒

| 页面 | 主要操作 |
|---|---|
| 健身 | 记录类型、时长、强度、卡路里和体重；查看统计及每周分析 |
| 出行 | 记录日期、交通、预算和同行人；生成逐日行程、接收出发提醒 |
| 消费 | 记录金额、分类、日期和支付方式；按月筛选、查看分类统计 |
| 定时任务 | 开关任务、修改执行时间和推送渠道、手动执行 |
| 通知 | 查看站内消息、推送结果和失败原因 |

「设置 → 渠道」可配置默认渠道、各类简报 / 提醒的渠道和通知组。通知组把多个渠道组合使用；具体定时任务可单独选择渠道。

飞书群 Webhook 用于推送，飞书应用机器人支持双向聊天。内网部署可选官方 SDK 长连接接收消息，生成网页要另行配置外部访问，见 [部署说明](部署.md#飞书机器人)。

### 早安、午间和晚间简报

1. 先在「设置 → 渠道」配置飞书群 Webhook 或 Server 酱；使用飞书应用机器人时，在「设置 → 飞书」配置应用及推送目标。
2. 进入「设置 → 简报」，分别设置早安简报、午间简报和晚间复盘的时间，勾选「每天定时推送」。执行时区显示在页面顶部。
3. 每类简报可以选择一个或多个推送渠道，也支持通知组。留空则继承「设置 → 渠道」中的定时简报渠道，再回退到默认渠道。
4. 点击「保存简报设置」。需要立即发送时，点击对应简报的「立即推送」；它使用已保存配置，不会保存尚未提交的修改。

三类简报都支持站内通知、飞书应用机器人、飞书群 Webhook 和 Server 酱。可在「通知」查看各渠道的发送结果和失败原因。关闭「每天定时推送」后，仍可手动推送。

## 多用户与消费 API

管理员在「设置 → 用户」创建账号，并将飞书 `open_id`（`ou_…`）绑定到对应账号。未绑定的飞书用户会收到绑定提示。日程、任务、笔记、聊天和生活记录按用户隔离，每位用户单独配置聊天模型密钥。

手机记账工具可使用消费 API。在「设置 → 账号」生成个人 Token，请求头任选一种：

```text
X-API-Token: <个人 Token>
Authorization: Bearer <个人 Token>
```

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/expenses` | 查询列表，可传 `start_date`、`end_date`、`category`、`limit` |
| GET | `/api/v1/expenses/stats` | 查询统计 |
| GET | `/api/v1/expenses/<id>` | 查询详情 |
| POST | `/api/v1/expenses` | 创建，JSON 字段为 `amount`、`category`、`date`、`payment_method`、`notes` |
| PUT / PATCH | `/api/v1/expenses/<id>` | 更新 |
| DELETE | `/api/v1/expenses/<id>` | 删除 |

个人 Token 只能访问自己的数据。旧配置中的全局 `API_TOKEN` 作为回退，数据归第一个管理员；未配置有效 Token 时接口返回 401。

## 设置入口速查

| 想调整什么 | 去哪里 |
|---|---|
| 账号、密码、时区、个人 Token、外观 | 设置 → 账号 / 外观 |
| 模型、候选模型、密钥、人设 | 设置 → 模型与人设 |
| 搜索、朗读 | 设置 → 联网搜索 / 语音 |
| 推送、飞书、简报 | 设置 → 渠道 / 飞书 / 简报 |
| 图片生成、识图 | 设置 → 图片 / 视觉 |
| 分享根地址和独立网页端口 | 设置 → 网页站点（管理员） |
| 立即备份、导出和保留策略 | 设置 → 备份 |
