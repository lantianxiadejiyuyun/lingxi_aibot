# 灵犀 Lingxi 2.0

Rust 后端 + Vue 3 个人 AI 工作空间。整理对话、待办、日程、笔记与生活记录，并为 QQ 群成员建立独立的人物记忆。

## 当前架构

- **后端**：Rust / Axum / Tokio / SQLx，版本化 API、流式聊天、持久任务和定时计划。
- **前端**：Vue 3 / TypeScript / Vite，组件化界面、响应式导航、Markdown 回复和群人物管理。
- **主人主库**：SQLite WAL，保存个人资料、主人的性格偏好及对话。
- **群成员独立库**：独立 SQLite 保存原文与证据，专用 Qdrant 保存人物向量，按账户、群号、QQ 号隔离。
- **图片与表情**：QQ 主人私聊支持纯图、图文和表情识别；模型看过喜欢才收藏，主人也可明确命令收藏。聊天时可从当前会话的收藏中挑选图片回复，私人图库与群图库隔离。
- **主动陪伴**：结合人设、主库记忆和近况，按个人时区与免打扰安排主动分享；支持站内、QQ 私聊、AstrBot、飞书和 Server酱。
- **B 站书房**：按兴趣发现视频，读取原始字幕并形成心得；支持扫码登录、定时阅读、字幕定位、阅读小记和主动陪伴引用。详见 [B 站书房](docs/B站书房.md)。
- **飞书私聊**：官方 Node SDK 已内置到应用镜像，随配置自动启动和停止；一次性身份绑定、持久收件箱与消息去重，主人的文字对话和记忆归入主库。详见 [飞书私聊](docs/飞书私聊.md)。
- **部署**：一个入口管理 Rust/Vue、内置飞书接入、NapCat 和专用向量库。管理员可从设置中心一键登录统一部署的 NapCat，无需翻日志复制登录密钥；已有外部 NapCat 也可继续使用。

## 开始使用

Linux 上使用下面的部署入口，自动生成密钥和首次 NapCat 配置、初始化管理员。默认地址是 `http://127.0.0.1:8000`。Windows 可在 WSL 运行，或按 [v2 部署与迁移](docs/Rust部署与迁移.md) 使用 Docker Compose 命令。

飞牛部署说明见 [fnOS 部署指南](docs/fnOS部署.md)。配置模板为 `.env.docker.example`，不再使用 MySQL 或 Flask 配置。

```sh
bash scripts/deploy.sh init --username admin
bash scripts/deploy.sh up
bash scripts/deploy.sh status  # 显示服务状态、灵犀与 NapCat 地址
# 升级前完整备份（短暂停机，完成后恢复原先运行的服务）：
bash scripts/deploy.sh backup
```

登录后先在「设置中心 → 模型与人设」连接自己的模型。管理员在「设置中心 → QQ 与群聊」一键登录 NapCat 管理界面，再扫码登录机器人 QQ，填写主人 QQ、机器人 QQ 和回调配置。在「QQ 群与会话」中逐个添加群，每个群有固定的独立会话，可分别选择模型、人设、回复和人物记忆开关；接入设置管理共用的主人 QQ、机器人 QQ、NapCat / OneBot、嵌入模型及专用向量库。统一部署的 OneBot 地址可以在页面直接采用，无需记忆容器 IP。

界面采用粉色 `#EABCDD`、浅粉 `#F0DFEA`、暖白 `#F7F6F5`、淡紫 `#DDD1E9`、雾蓝 `#A4B5D5` 的统一主题。颜色集中在 `web/src/styles/tokens.css`，布局和组件样式分别维护。临时连接失败保留登录信息并提供重连入口；设置分页通过 URL 保留当前栏目。

QQ 私聊开启后即可发图，默认沿用对话模型，也可在「设置中心 → 习惯与偏好 → 图片与表情」指定支持图片输入的看图模型。图片收藏默认关闭；开启后由模型判断，或附图、回复图片说「收藏这张图」。每条最多识别 4 张、单图 8 MiB；GIF 按时间顺序抽取最多 10 帧识别，不足 10 帧读取全部帧，发送保留原文件。详见 [图片收藏说明](docs/Rust部署与迁移.md#qq-图片与表情收藏)。

识图遇到临时接口故障、流式中断或不完整的结果时，会在当前处理任务内最多重试一次；支持带代码块或简短前言的 JSON 说明。认证、权限与图片请求配置错误不会反复调用。失败时区分原因，私聊图片归档记录失败类别和尝试次数；重试继续使用同样的 GIF 抽样帧。连续 QQ 私聊任务按账号依次处理，避免多张图片同时抢占会话；识图重试不会重发聊天消息。

自动表情回复要求模型明确给出至少 **75% 的发图意愿**，无有效评分只发文字。每个会话至少间隔 5 分钟、穿插两轮文字，同图 30 分钟内不重复，每小时最多 3 次；私聊和各群独立计算，群内主人与成员共享同一限额。正常回复和延迟补充共用这些规则；发送结果不确定也会占用限额，重启不会清零。

群回复默认不 @发送者。在「设置中心 → QQ 与群聊」可开启「群回复时 @发送者」，各群设置也可单独覆盖；开启后仅第一条回复提醒一次，不影响「被 @ 时回复」的触发规则。

各群设置提供独立的「自动接话频率限制」和「表情发送频率限制」，默认开启。关闭前者可取消自动接话的间隔与每小时条数上限；关闭后者可取消该群表情的冷却、穿插文字、同图间隔与小时次数限制，75% 发图意愿门槛仍生效。开关不会清除发送记录，重新开启后按已有记录限频；不影响其他群和主人私聊。自动接话仍需规则或模型判断，本地判断模型的调用额度和并发保护继续生效。

人设养成按最多 6 个片段分批整理，输出截断或上下文不足时缩小批次，已完成批次不会因后续失败丢失。「人设养成 → 立即整理」可手动处理待整理片段，跳过自动整理的数量与时间门槛，仍遵守养成开关和权限。模型编辑器提供上下文容量与最大输出的独立常用值，支持自定义；养成整理使用配置的输出预算。

主动陪伴默认关闭，在「设置中心 → 习惯与偏好」设置时段、频率、兴趣和接收渠道。保存后按计划检查，没有合适内容时保持安静。AstrBot 的绑定也在此栏目，个人 QQ 在「QQ 与群聊」，飞书和 Server酱在「飞书与通知」配置，详见 [主动陪伴说明](docs/Rust部署与迁移.md#主动陪伴与私聊连接)。

## 功能与权限

「设置中心 → 功能与权限」提供 AI 总开关和 10 项功能开关，每项可分别授权个人会话（网页、QQ、飞书、AstrBot）与 QQ 群聊。权限与接入、计划必须同时允许才会执行；联网搜索（含读取网页）独立于 AI 工具，关闭工具仍可搜索。群聊可单独开启相处习惯养成、群视频字幕阅读和共享记录工具，新开放的群权限默认关闭。各群仍保留独立的会话、模型及群内功能设置。

开关自动保存，后台在处理消息、调用工具和投递主动消息时重新检查。关闭不会删除历史、密钥或既有配置；已经发出的消息或开始的外部请求无法撤回。手动整理记录、记忆和绑定渠道仍可使用。未设置权限的旧账户沿用原行为，不会自动启用尚未配置的功能。权限只控制当前账户的 AI 能力，不改变管理员角色。

群习惯只采纳当前成员有原文依据的交流反馈，不覆盖基础人设；B 站只读取群内明确提供的视频字幕（每群每日最多 6 次尝试），不会调用私人兴趣计划。共享记录支持本群笔记、待办、日程的查询、保存和删除；不开放私人文件、下载目录或私人后台任务。上述资料保存在 QQ 数据库，按账号与群号隔离，可在「打开群会话 → 这个群积累的小记」查看和删除。开放群联网搜索后可搜索公开资料及读取公网网页，不能借用管理员的私网访问权限。

群回复区分成员与助手的历史角色，当前问题只出现一次。自动接话经判断模型筛选后，回复模型仍可选择安静；新消息到达时撤销过时的自动接话。延迟补充会避开与最近回复重复的内容。开启分段回复后，QQ 私聊、群聊和飞书按空行分段依次发送，不机械拆句；各群独立设置，QQ 与飞书私聊共用私聊节奏，仍保留最多条数和间隔控制。

设置 API 为 `GET /api/v2/permissions` 与 `PUT /api/v2/permissions`，后者提交完整配置。使用页面管理即可，无需修改数据库。

## 记忆如何归属

| 身份 | 对话记录 | 性格与偏好 |
|---|---|---|
| 主人 | 主库中的专属会话 | 主库长期记忆 |
| 其他群成员 | 独立群成员 SQLite | 独立元数据 + 专用 Qdrant 向量库 |

身份只由配置的数字 QQ 号决定，不依赖昵称。性格观察保留原文依据、置信度和有效期，可查看、修正、删除。群聊回复不加载主人私人会话、私人记忆或个人工具。

## 开发与验证

```sh
npm ci --prefix web
npm run build --prefix web
npm test --prefix web
cargo test --workspace --locked
cargo run --bin lingxi -- serve
```

另开终端运行 `npm run dev --prefix web`，即可使用 Vite 开发服务。技术说明见 [Rust / Vue 架构](docs/Rust-Vue架构.md)。

## 迁移状态

v2 已重写核心记录、聊天、记忆、任务、主动陪伴与私聊接入，并新增 QQ 群人物分库。复杂多 Agent / 媒体工作流、重复日程实例展开和部分专用渠道协议尚未全部迁移，详见 [功能差异](docs/Rust部署与迁移.md#与-v1-的功能差异)。

当前分支已移除 Python / Flask 后端、重复部署源码和旧后端测试，只构建 Rust / Vue。Python 仅用于可选的 AstrBot 插件、旧数据库导出和源码打包，不参与灵犀服务运行。

旧实现可从 Git 提交 `2f8915f` 查看；历史说明与配置保存在 [v1 资料归档](docs/legacy/README.md)，不适用于当前版本。迁移仍使用 `scripts/export_legacy.py` 和 Rust 导入命令，回退需原部署及数据备份。
