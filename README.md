# 灵犀 Lingxi

[![License: PolyForm Shield](https://img.shields.io/badge/license-PolyForm%20Shield-blue)](LICENSE)

一个可以自己部署的 AI 个人助理。通过网页或飞书聊天，管理日程、任务、笔记和生活记录，也能生成可分享的网页。

## 开始使用

**推荐使用 Docker 部署**，适合 Linux 服务器和飞牛 fnOS：

1. 按 [首次安装](docs/部署.md#首次安装) 启动应用和 MySQL。
2. 使用初始化时生成的管理员密码登录后台。
3. 打开「设置 → 模型与人设」，填写自己的模型接口、API Key 和模型 ID。
4. 进入「AI 助手」，试着说：“明天下午 3 点提醒我开会。”

已有部署请看 [升级步骤](docs/部署.md#升级)。本地开发、宝塔和普通 Linux 部署分别见 [开发指南](docs/开发指南.md) 和 [部署参考](docs/部署参考.md)。

## 能做什么

| 功能 | 用法 |
|---|---|
| AI 助手 | 流式对话、调用工具办事、多组模型与提示词切换、思考等级和长上下文管理 |
| 工作管理 | 日历、重复日程、任务、笔记、定时提醒、早午晚简报和周月报；每天的简报自动汇总为日历中的一条日报 |
| 生活记录 | 健身打卡、出行计划与行程、消费记账 |
| 内容生成 | 生成网页与图片，配置公网地址后直接返回分享链接 |
| 搜索与记忆 | 联网调研、知识库检索、长期记忆；支持 AI 编写技能并由用户审核启用 |
| 多端使用 | 网页与飞书机器人、多用户数据隔离、站内通知及外部推送 |
| 外部接入 | 每账号 Token、日程与待办 REST API、AI 对话 SSE 与 WebSocket |
| 文件与番剧 | 本机硬盘和 NAS、AI 搜源、qBittorrent/aria2 下载、停滞重试和失败后自动重新搜源 |
| 后台代理 | 框架内部多轮工具调用、最多三个并行子代理、共享预算、任务进度与恢复 |

支持 OpenAI 兼容接口和 Anthropic Messages 协议。每位用户单独配置模型密钥；图片、识图、语音和向量检索服务可按需配置。

对话模型、提示词、图片生成、备用视觉均可保存多组配置并快速切换。读图优先使用当前模型的原生视觉能力；上下文按模型实际容量填写，支持 100 万、200 万 token 及自定义档位。

## 常用聊天命令

以下命令在网页聊天和飞书中通用，直接作为一条消息发送：

| 命令 | 用途 |
|---|---|
| `/` 或 `/help` | 查看帮助 |
| `/profile`、`/prompt`、`/image`、`/vision` | 查看四类配置组；后接序号或 ID 切换，如 `/profile 2` |
| `/model` | 查看当前模型及候选列表 |
| `/model 2` | 切换到候选列表中的第 2 个模型，也可填写完整模型 ID |
| `/think` 或 `/think high` | 查看支持的思考等级，或选择一个等级 |
| `/auto on`、`/auto off` | 开关 AI 自主切换模型与思考等级 |
| `/context` 或 `/status` | 查看当前会话状态与上下文用量 |
| `/compact` | 压缩较早上下文，保留完整聊天记录 |

这些操作只影响当前会话。先在「设置 → 模型与人设」填写候选模型；手动切换后会锁定选择，可用 `/auto on` 恢复自主切换。详见 [模型与上下文](docs/使用指南.md#模型与上下文)。
