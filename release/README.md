# 发行目录

本文件夹专门放**对外分发的安装包**，与开发仓库分开。

| 路径 | 说明 |
|---|---|
| `lingxi/` | 最新一次打包出的发行树（上传服务器、解压即用） |
| `lingxi-v*.zip` | 同一份内容的压缩包（宝塔文件管理可直接上传） |
| `README.md` | 本说明 |

`lingxi/` 和 zip **由脚本生成**，不要手改这里的代码。改功能请改仓库里的 `app/`，再重新打包。

## 重新打包

在仓库根目录：

```powershell
python scripts/pack_release.py
```

不要 zip 时加 `--no-zip`。

包内不含：`.venv`、`.env`、数据库备份、测试脚本、旧 `deploy/` 快照。密钥和数据由用户在服务器上自己生成。

部署步骤见打包结果里的 `lingxi/开始使用.md` 和 `lingxi/docs/部署.md`。
