# 发行目录

这里存放由当前仓库代码生成的安装包。

| 路径 | 说明 |
|---|---|
| `lingxi/` | 生成的应用、配置模板和文档 |
| `lingxi-v*.zip` | 同一份内容的压缩包 |
| `README.md` | 本说明 |

安装时从包内 `开始使用.md` 开始，推荐 Docker 快速安装。两个 MySQL 密码需自行填写，运行数据在安装时创建。

## 生成安装包

在仓库根目录：

```powershell
python scripts/pack_release.py
```

只生成目录时加 `--no-zip`。脚本会重建 `release/lingxi/`，不要把正在运行的服务或个人数据放在该目录；需要修改代码时，先修改仓库源码再打包。

包内包含 Docker 快速安装与高级编排、两份 `.env` 模板及完整文档导航。不含真实 `.env`、运行数据、数据库备份、虚拟环境、测试脚本或旧 `deploy/` 快照。

安装与升级见 [部署说明](../docs/部署.md)，功能用法见 [使用指南](../docs/使用指南.md)。升级时保留服务器上的配置、`data/` 和数据库卷。
